# obx-guide

Static site for **guide.obx.deals** — a town-by-town OBX area guide.
Part of the `obx.deals` network (see `tiddnet/rental-intel` ADR 0215,
which supersedes ADR 0053's stale Streamlit-based design).

Plain static HTML, no build step, hosted on GitHub Pages. Custom domain
via `CNAME` file + Route53 CNAME record (`terraform/main.tf` in
`rental-intel`).

## Structure

- `index.html` — landing page, towns grouped by region
- One folder per town (`corolla/`, `duck/`, ... `ocracoke/`) — profile
  page: tagline, character, best-for/not-ideal-for, access facts, and
  numbers (rental count, distance, size range, summer rate range)
- `faq/` — 20 question pages plus an index. Each page lists its sources
  and the date they were checked.
- `sitemap.xml`

## Do not edit the HTML by hand

Every page is generated by `scripts/generate_guide_pages.py` in
`tiddnet/rental-intel` (ADR 0510). Copy lives there in
`data/guide/towns.json` and `data/guide/faq.json`; town numbers are
refreshed from the search database. To change a page, change the data
file and regenerate:

    cd ~/git/rental-intel
    .venv/bin/python -m scripts.generate_guide_pages --refresh-stats \
        --search-db /Users/loaner/prod/rental-intel/data/search.db
    .venv/bin/python -m scripts.generate_guide_pages --search-out ~/git/obx-search

Then commit and push this repo; GitHub Pages redeploys automatically.

Distances are straight-line, labeled as such. Rental counts for the
Hatteras Island towns are shown as a minimum ("250+") until Surf or Sound's
houses can be placed in the right village (rental-intel ADR 0511).
